## 2026-11-17: Results site: the headline is each model's pass rate with test prints first, with what a working part took and how settled the order is (no result changed)

The top of the results site showed three pooled numbers, one per condition (37% on the first print, 62% after feedback, 53% with test prints first). Dan found three conditions confusing as a headline and cares about the models, not the pooled totals. The headline is now one bar per model, its pass rate on the four scored parts when it can ask for test prints before its final design, best first, with what each passing design took beside it: print hours and filament (slicer estimates, test prints included) and API cost. Each row opens the trials it counts. First prints and reprints after feedback stay in the scorecard further down, which the note links to.

Test prints first leads because it is the way of working the eval is about, and because a final print that fails counts as a failure: that is where the hours and filament are lost, even after test prints (Dan, 2026-11-17). It is not the condition with the highest pass rate; reprint after feedback is, at 62% for the six models whose first prints were sent back. The note says what a pass means and that no final design was printed.

Under the chart, a line says how settled the order is, from a new `rank_odds` block in the site's scorecard data (`scripts/results_site.py`). Every model's test-prints-first passes were redrawn task by task, 20,000 times with a fixed seed (a binomial at each task's saved pass rate and number of trials). Only the four scored tasks are redrawn, the same trials the chart counts (Codex, PR #53: the first version also redrew the harder Estoa task). From today's saved runs: Gemini 4 Argon ranks first in 98% of the redraws, GPT-6.1 Sol is in the top two in 66%, and Haiku 5.5 ranks last in 98%; Opus 5.5, Gemini 3.8 Flash, DeepSeek V4.1 Flash and Sonnet 5.5 can't be put in order. The line says this is trial-to-trial noise on these four tasks only.

How it was chosen: Jev, GPT-6 Luna Decisions, Gemini Decision 1 and Codex were asked how to show the results. All four warned against ranking neighbors in the middle of the table, which the rank-odds line answers. No grade, finding or saved run changed. Checked in a local build at desktop width and 375 px (the cost columns fold away on a phone; no sideways scroll). Site tests: 73 passed.
