## 2026-11-14: Results site: "after one round of feedback" counted a model that got no feedback; the headline is 62% of 241, not 54% of 281

No grade, saved result or README number changes. The site's own headline was wrong.

The site's second headline number read "54% after one round of feedback, 151 of 281", with the caption "the same first prints; each one that didn't pass was sent back once". It pooled all seven models that were also run with test prints first. One of them, Haiku 5.5, never had its failed first prints sent back (`scorecard.Row.replayed()` is false for it, and the README's table says "not run" in that column), so its 39 first prints that didn't pass were counted as after-feedback failures and the caption was false for them. 151 of 281 was the six replayed models' 150 of 241 plus Haiku's first-print 1 of 40. The README never states a pooled after-feedback rate; the site's generator made this one (`scorecard_block`, in the site's first PR), and three of the site's tests asserted it.

Now the after-feedback headline counts only the models whose failed first prints were sent back: **62%, 150 of 241, six models**. Beside it the page gives those same six models' first prints alone, **43%, 104 of 241**, so before and after are like for like, and names the model left out. The first-print headline (37%, 105 of 281, seven models) and the test-prints-first headline (53%, 116 of 219) are unchanged. The chart's "Headline" row, the title and description a shared link shows, and the page's own count check follow the same rule. The number still opens exactly its designs: the model filter gains a value for these six (`?model=sent-back`).

A second adversarial design review found it, from the chart's own rows: the headline row added up a model sitting under "First print only". I confirmed it from the saved results before changing anything: each of the seven models' `replayed` flag and its first-print and after-feedback counts, and the README's column.

Evidence: `tests/test_results_site.py` (26 pass). The three tests that asserted the old pooling now assert the rule, and a new one checks that the after-feedback set is replayed models only, that the page names who is left out, and that the old caption is gone. In the browser the tile reads 62%, 150 of 241, its link opens 241 designs, and the page's own check reports 0 problems of 1,913 comparisons.

Codex's review found one fault, fixed before merging: the menu offered the six-model set only where the larger seven-model set also narrowed the list. Under "test prints first" every listed model is one of the seven, so after following the headline and switching condition the menu read "All models" over a list still filtered to six. Each set is now offered wherever it narrows the list, and always while it is the one chosen. Checked in the browser: with the six chosen under "test prints first" the menu shows them selected, over 199 trials from six models.
