## 2026-11-13: An LLM judge checks whether each failure drawing shows its failure (no result changed)

Each failing check on the results site has a drawn 2D figure of what the check looked at (`scripts/results_site_views.py`). To see whether those figures are legible, a decisions model was asked one typed yes/no question about each one: "Does this image show this failure clearly enough for a person to see what is wrong?" It got the image (as JPEG) and the check's caption, which is the title plus the finding's detail. No verdict, grade or count changed. The answer is a note attached to the view, never a grade.

- **Judge.** Jev 1.14 (`typesafe/jev-1.14-20261014`) through OpenRouter's Decisions API, using the client in `pbe/judges/decisions.py`. It's the default judge in `docs/decisions-api.md` and isn't a contestant. **This is an LLM judging pictures.**
- **What was judged.** Every view with state "fail" in `scripts/results_site_views.json` (version 5, after the drawings were redrawn): 775 views, which use 693 distinct images (some identical designs share a drawing). That covers 742 counted failures and 33 failed test prints. 181 of the images were judged in the first run against the version 4 drawings and are unchanged since. The other 512 were judged after the redraw. Views of ungraded checks were left out, because the question asks about a failure and an ungraded check has none to show. The first run's 517 answers for images that were since redrawn or dropped stay in `view-audit.jsonl` as the record of what ran, and are left out of every share.
- **Result.** At p(yes) ≥ 0.5, 767 of 775 current views pass (99.0%): 735 of 742 counted failures and 32 of 33 test prints. The weakest kinds were `screw-cut` (0 of 2), `enclosure-cut` (19 of 23), `pieces` (26 of 27) and `bridge-layer` (318 of 319). 66 images got a p between 0.3 and 0.7. Per task, check and kind: `results/judges/2026-11-13/view-audit-summary.json`. On the first run (version 4 drawings) it was 773 of 785 (98.5%).
- **Hand check** (`results/judges/2026-11-13/view-audit-hand-check.md`), on the first run's images. Claude, also an LLM, looked at 10 images picked across kinds and answers, and wrote its own answer before comparing. They agreed on 7 of 10. Claude agreed with all 6 of the judge's "yes" answers but only 1 of its 4 "no" answers. The other three "no" answers were drawings Claude found legible: two labelled parts, a plain back with no keyholes, and a small red roof strip. The one agreed "no" was a real defect: the bearing-wheel R4 drawing showed only the bolt's outline, with no wheel. Since the redraw that view has no drawing, and the manifest says why: the wheel built as a flat sheet. Nine of the ten images have since been redrawn, and the file lists their new scores without new hand judgments. Dan's column is empty.
- **Cost.** $0.133 over both runs, 1,210 calls: $0.075 for 698 calls on the first run (including a 10-call dry run, $0.0010) and $0.058 for 512 calls after the redraw. That's about $0.00011 per call, mostly the image's roughly 2,600 input tokens at $0.042 per million. The cost comes from the provider's reported usage. The budget was $2.
- **Site.** `scripts/results_site_view_audit.json` maps each current failed view's URL (693) to `{shows_failure, p, model}`. An answer counts only if it was given for the same image bytes, caption and question version. `scripts/results_site.py` attaches it as `view.audit` and works without the file. Tests in `tests/test_results_site.py` check that every audit entry names an existing view, that p is in [0, 1], and that a missing file is fine.
- **Limits.** A "yes" means the judge found the captioned thing in the picture. It doesn't mean the picture, or the check, is right. With 98.5 to 99% "yes" and its "no" answers mostly wrong in the hand check, the judge barely separates good drawings from bad ones. Treat a low p as a pointer to a drawing worth a look, not a finding. One model and one question version, and each image judged once; the probabilities vary from run to run (`docs/decisions-api.md`).

Reproduce: `uv run python scripts/results_site_view_audit.py --budget 2` (resumable; `--limit 10` for a trial run, `--summarise` to rewrite the summary and the site file without calls).
