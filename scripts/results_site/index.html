Functional 3D Printing Eval

Can a language model design a part that prints and works?

Language models were asked, in a person's own words, for a part to 3D print. Of their designs, this many pass:

 on the first print   after one round of feedback the same first prints; each one that didn't pass was sent back once  asking for test prints first fewer trials ran; in some the person couldn't say how a test piece came out

A pass means every check passes against test prints that Dan, the eval's author, printed and recorded. Nothing a model designed was printed: code graded each design against those records, and where no record decides a check the design is not graded, never a pass.

Why this eval

3D printing is becoming far more accessible to the general public, as state of the art printers have become cheaper while increasing their capabilities, and LLMs can generate designs using open source tools, without a user needing to learn 3D modeling or purchase expensive software.

In the design process, these models often make mistakes, which are costly both in time and money, as prints can take hours to complete, and physical material is consumed. If there are errors, another print needs to be made, thus wasting the time and material spent.

How can we determine which models produce the best designs, with the least amount of tokens spent, material consumed, and time waited for printing? How can we simulate the result of each print design, and know if it will be successful or not before printing it?

This is a framework for simulating and measuring the success when LLMs are designing functional prints based on a prompt, measurements, available materials, and simulated results. How it works, on GitHub.
